# TBO-Budget-App

## Requirements

- **C++17** or newer
- **Qt 6.5** or newer
- **CMake 3.16** or newer
- **C++ Compiler** (GCC, Clang or MSVC)
- **Qt Modules:** Quick, Quick Controls 2, QML

### Supported Platforms
- Linux
- Windows (not tested - should work)
- macOS (not tested - should work)

### Build & Run

```bash
cmake -S . -B build
cmake --build build
```

**Linux:**
```bash
./build/bin/TBO
```

**Windows (MSVC):**
```powershell
.\build\bin\Debug\TBO.exe
```
